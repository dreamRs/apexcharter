# Worldwide Blockbusters 2019-1977

The dataset contains data about about blockbusters gross (in millions
USD) by genre and per year between 1977 and 2019.

## Usage

``` r
blockbusters
```

## Format

A data frame with 183 observations and 3 variables.

## Source

Kaggle
(<https://www.kaggle.com/datasets/narmelan/top-ten-blockbusters-20191977>)
